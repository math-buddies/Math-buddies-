# Math Buddies 🦊
An original, story-based elementary math web app for grades 1–5.

## Features
- Four adventures: Finn’s Lost Star Map, Pip’s Rainbow Bridge, Luna’s Moon Lantern, and Captain Coco’s Treasure
- Addition, subtraction, multiplication, division
- Ten-question missions, visual clues, step-by-step explanations, instant feedback
- Earn stars and unlock the next story chapter after each mission
- Progress saved only in the browser; no account, personal information, or backend required
- Responsive for phones, tablets, and computers

## Play locally
Open `index.html` in a browser. Or serve the folder with `python3 -m http.server 8000`.

## Deploy on Vercel
Import or upload the `math-buddies` folder to a new Vercel project, select Framework Preset **Other**, then deploy. With an authenticated Vercel CLI, run `vercel deploy --prod` from this directory.
